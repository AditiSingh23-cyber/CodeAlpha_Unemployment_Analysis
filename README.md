# CodeAlpha Unemployment Analysis

## Project Overview
This project analyzes unemployment rate trends in India using Python. The analysis focuses on data cleaning, exploration, visualization, Covid-19 impact analysis, and identifying important unemployment patterns and trends across different regions and time periods.

## Objectives

- Analyze unemployment rate data representing unemployed people percentage
- Perform data cleaning and preprocessing
- Explore unemployment trends using Python
- Visualize unemployment patterns across regions and time periods
- Investigate the impact of Covid-19 on unemployment
- Identify seasonal and economic trends in unemployment data
- Generate insights that may support economic and social policy decisions

## Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Files
- Unemployment_Analysis.ipynb
- unemployment_data.csv

## Conclusion
The project identifies unemployment trends across different regions and time periods using visualization and statistical analysis.
